📍 SERVICE URLS (After running ./start.sh)
═════════════════════════════════════════════════════════════════════════════

🌐 FRONTEND (Web UI - OPEN THIS IN YOUR BROWSER)
   URL: http://localhost:3000
   Type: Web Interface
   Access: Any web browser (Chrome, Firefox, Safari, Edge, etc.)
   
   Features:
   • Image upload (drag & drop or click)
   • Real-time detection
   • Bounding box visualization
   • Confidence score display
   • Response metadata

🔌 UI BACKEND (REST API)
   URL: http://localhost:5000
   Type: REST API Server
   Endpoints:
   • POST /api/detect          - Submit image for detection
   • GET /api/status/<id>      - Get results by request ID
   • GET /health               - Health check

🤖 AI BACKEND (YOLOv3 Inference)
   URL: http://localhost:5001
   Type: Machine Learning Service
   Endpoints:
   • POST /api/detect          - Run object detection
   • GET /health               - Health check

═════════════════════════════════════════════════════════════════════════════
⚡ QUICK START
═════════════════════════════════════════════════════════════════════════════

1. Make script executable:
   $ chmod +x start.sh

2. Start all services:
   $ ./start.sh

3. Open browser and navigate to:
   http://localhost:3000

4. Upload an image and click "Detect Objects"

═════════════════════════════════════════════════════════════════════════════
📊 WHAT EACH URL DOES
═════════════════════════════════════════════════════════════════════════════

http://localhost:3000
└─ User uploads image
  └─ Frontend sends to http://localhost:5000/api/detect
    └─ UI Backend routes to http://localhost:5001/api/detect
      └─ AI Backend runs YOLOv3 inference
        └─ Returns detection image + JSON results
          └─ Frontend displays results to user

═════════════════════════════════════════════════════════════════════════════
✨ EXAMPLE WORKFLOW
═════════════════════════════════════════════════════════════════════════════

1. User opens http://localhost:3000 in browser
2. User drags image onto upload area
3. User clicks "🔍 Detect Objects" button
4. Frontend sends to backend API
5. YOLOv3 model processes image
6. Results returned as JSON + image with bounding boxes
7. Frontend displays results with confidence scores
